💡 Comment est calculé votre score ?

Le score Sylanty combine 3 facteurs :
  • Criticité du document — Critique (×3), Obligatoire (×2), Recommandé (×1)
  • Coefficient NAF — adapté à votre métier (ex: Qualifelec ×2 pour électricien, Décennale gros œuvre ×2.5 pour maçon)
  • État du document — Valide (100%), Expire dans 30-60j (70%), Expire <30j (30%), Manquant (0%)

Grade A+ ≥ 90%, A ≥ 80%, B ≥ 70%, C ≥ 60%, D < 60%.
